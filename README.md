# MangaList

Личный трекер прогресса чтения манги/манхвы + учёт дропа коллекционных карт и осколков (Senkuro).

Один HTML-файл, без сборки и зависимостей на бэкенде. Все данные хранятся в `localStorage` браузера.

## Возможности

**Вкладка «Манга»**
- Карточки тайтулов: обложка, статус (Читаю / Планирую / Прочитано / Брошено), прогресс по главам
- Ручной ввод текущей главы, поддержка дробных номеров (побочные главы вида 45.5)
- Поиск обложки через AniList или загрузка своей картинки (с авто-сжатием)
- Фильтры по статусу, сортировка (по названию / прогрессу / недавним обновлениям)
- Проверка обновлений глав у источника (через прямой запрос или CORS-прокси)
- Необязательная синхронизация между устройствами через свой Supabase-проект

**Вкладка «Дропы карт»**
- Учёт выпадения карт по рангам (F, D, C, B, A, S) и осколков (oD, oC, oB, oA, oS)
- Пакетное добавление за один день сразу по нескольким рангам
- Статистика (графическая и текстовая) с процентным соотношением за выбранный диапазон дат
- Разбивка по дням
- Импорт из Excel/CSV

**Вкладка «Осколки»**
- Инвентарь осколков, которые сейчас на аккаунте: название, тайтл-источник, ранг, количество, стоимость
- Импорт из Excel/CSV с автоматическим разбором «Имя (Тайтл)»
- Статистика по рангам

## Запуск

Открой `index.html` в браузере — либо локально, либо через GitHub Pages (Settings → Pages → Deploy from branch → `main` / `root`).

## Данные

Все данные (список манги, дропы, осколки) хранятся только в localStorage твоего браузера. Ничего не отправляется на сторонние серверы, кроме:
- поиска обложек через AniList (по явному запросу),
- проверки обновлений глав у источника (по явному запросу),
- синхронизации через Supabase, если её включить и настроить самостоятельно.
